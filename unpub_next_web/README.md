# unpub_next_web

Web front-end interface for `unpub_next`.

> [!NOTE]
> **Fork Notice**: `unpub_next_web` is part of the `unpub_next` fork of [`pd4d10/unpub`](https://github.com/pd4d10/unpub) (which was no longer actively maintained).

A web app that uses [AngularDart](https://webdev.dartlang.org/angular) and
[AngularDart Components](https://webdev.dartlang.org/components).
The compiled static assets (`index.html.dart` and `main.dart.js.dart`) are embedded into `unpub_next` to serve the web UI out-of-the-box.
